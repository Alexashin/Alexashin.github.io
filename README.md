## Как устроен сайт

Статический сайт на [Astro](https://astro.build): обычный HTML и CSS, почти без JavaScript, поэтому он быстрый и не требует сервера с базой. Публикуется на GitHub Pages через GitHub Actions при каждом пуше в `main`.

- **Проекты** лежат в `src/content/projects/<slug>/`: `index.md` с описанием и скриншоты рядом.
- **Услуги и цены:** `src/content/services/*.md`.
- **Достижения и публикации:** `src/content/achievements/*.md`.
- **Имя, контакты, письмо «Обо мне», шаги «Как работаю»:** `src/data/profile.ts`.
- **Картинки** сборка нарезает сама: версии от 480px до родной ширины скриншота (не больше 1920px), больше исходника кадр не растягивается. Чем крупнее исходный скрин, тем чётче сайт на экранах высокой плотности.

### Запуск у себя

Нужен Node 22.

```
npm install
npm run dev      # разработка на localhost:4321
npm run build    # проверка типов и сборка в dist/
```

### Новый проект

1. Создать папку `src/content/projects/<slug>/` и положить в неё скриншоты.
2. Скопировать `index.md` любого проекта и поменять поля: название, тип, год, стек, цифры, обложку, кадры, текст кейса. Ошибка в поле будет видна при `npm run build`.
3. Цифры в `metrics` только подтверждённые. Персональные данные клиентов на скриншотах скрыты.

### Яндекс Метрика

Задать переменную `PUBLIC_YM_ID` при сборке (в Actions: Variables репозитория). После подключения дополнить раздел про аналитику в `src/pages/privacy.astro`.
