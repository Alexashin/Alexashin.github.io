# Сайт-портфолио Артема Алексашина

Статический сайт на Astro. Публикуется на GitHub Pages: https://alexashin.github.io

## Как добавить проект
1. Создать папку `src/content/projects/<slug>/` и положить в неё скриншоты.
2. Скопировать `index.md` любого проекта, поменять frontmatter (название, тип, год, стек, цифры, обложка, кадры) и текст кейса.
3. `git push`: сайт соберётся и обновится сам. Ошибка в поле видна при сборке (`npm run build`).

Цифры в `metrics` только подтверждённые. Названия заказчиков в тексте обезличены (поле `client`).

## Услуги, тексты и достижения
- Прайс-лист «Услуги и цены»: `src/content/services/*.md` (группа, позиции с ценой и ссылкой на проект-пример)
- Достижения и публикации: `src/content/achievements/*.md`
- Имя, контакты, фото, письмо «Обо мне», шаги «Как работаю»: `src/data/profile.ts`

## Картинки
Скриншоты кладутся в папку проекта как есть, в максимальном разрешении. Сборка сама нарежет версии от 480px до родной ширины (не больше 1920px) и никогда не растягивает кадр больше исходника. Чем крупнее исходник, тем чётче сайт на экранах высокой плотности: снимать лучше с масштабом 2x.
`public/og.png` (превью ссылки в мессенджерах) снимается с первого экрана главной, 1200×630.

## Запуск
```
npm install
npm run dev      # разработка
npm run build    # проверка типов и сборка в dist/
```
Нужен Node 22 (Astro 5).

## Яндекс Метрика
Задать переменную `PUBLIC_YM_ID` при сборке (в Actions: Variables репозитория). После подключения дополнить раздел про аналитику в `src/pages/privacy.astro`.
