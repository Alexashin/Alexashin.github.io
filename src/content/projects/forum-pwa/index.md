## Бизнес-задача
Дать участникам форума удобное приложение вместо перегруженного сайта: программа, схема залов, участники, партнёры. В залах слабая связь, поэтому всё должно работать без интернета.

## Решение
Progressive Web App: ставится на экран телефона, открывается мгновенно и без сети. Данные берутся с сайта организаторов автоматически и обновляются по расписанию.

## Что получил клиент
- Участник открывает программу и схему даже при плохой связи.
- Организаторам не нужно вручную переносить программу: данные обновляются сами раз в 3 часа.
- Установка в один тап, без магазина приложений.

## Какие вопросы закрыты
Доступ к программе без сети, актуальность данных, независимость от магазинов приложений.

## Технические моменты
- Service worker: предзагрузка 27 ресурсов, для данных и скриптов сначала сеть, для остального сначала кэш, старые кэши удаляются при обновлении.
- Парсер блоков конструктора сайта (Python): расписание, спикеры, участники, нормализация текста.
- GitHub Actions по расписанию снимает данные, коммитит изменения и публикует на GitHub Pages.
- На момент снимка: 17 событий, 87 участников, 84 спикера.

## Что можно улучшить (честно)
Нет автотестов; качество парсера держится на ручной проверке.
