## Бизнес-задача
Звукорежиссёру нужно сводить барабаны из записей с нескольких микрофонов. Один MIDI-удар должен запускать все микрофонные записи синхронно и разводить их по отдельным каналам DAW без ручной настройки.

## Решение
Плагин VST3 и Standalone на C++ / JUCE: один удар, до 16 микрофонов, 16 моно-выходов плюс стерео, слои velocity, вариации, микшер Solo/Mute, редактор партии, свои форматы библиотеки.

## Что получил заказчик
- Библиотека, защищённая от копирования и удобная в работе: сэмплы в зашифрованном формате.
- Автоматическая раскладка по выходам DAW (вместо ручной маршрутизации).
- Проверка на реальном DAW (Cubase 15 частично, остальное в плане).

## Технические моменты
- Формат `.splpack`: FLAC-блоки, шифрование XChaCha20-Poly1305, лицензия подписана Ed25519, сервер лицензий на Python (выключен по умолчанию по решению проекта).
- Audio thread: владение данными кита через hazard pointer, без блокировок в `processBlock`, потоковое чтение с диска через кольцевые буферы, общий реестр декодированных клипов между экземплярами.
- Проверка `pluginval` уровня 5 на Release VST3.
- Разделение: `core/` без GUI, `plugin/`, `tools/` (упаковщик, разметчик, сервер лицензий), `tests/`.

## Честные ограничения
Чистая Windows и слух не проверены, macOS/AU только в плане. Аудиоматериал принадлежит правообладателю библиотеки и в публичные материалы не входит.
